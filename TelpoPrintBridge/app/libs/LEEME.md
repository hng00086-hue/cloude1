# Copia aquí el SDK de Telpo

Pon en esta carpeta el `.jar` o `.aar` del SDK de Telpo para el TPS320
(el que trae la clase `com.telpo.tps550.api.printer.UsbThermalPrinter`).
Si el SDK trae librerías nativas (`.so`), cópialas en `app/src/main/jniLibs/armeabi-v7a/`.
